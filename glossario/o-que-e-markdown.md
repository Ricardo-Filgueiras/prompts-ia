---

## 📌 Definição Simples

**Markdown** (arquivos com extensão `.md`) é uma linguagem de marcação ultra leve criada para formatar textos usando símbolos simples do teclado (como `#`, `*`, `-` e ```` ``` ````).

É o formato padrão utilizado no GitHub, Notion, Obsidian e por desenvolvedores do mundo todo para criar documentações bonitas, organizadas e fáceis de ler.

---

## ✍️ Sintaxe Básica do Markdown

Abaixo estão os símbolos mais comuns usados nos arquivos deste repositório:

| O que você digita | Como aparece formatado |
| :--- | :--- |
| `# Título Principal` | **Título Grande (H1)** |
| `## Subtítulo` | **Título Médio (H2)** |
| `**Texto em negrito**` | **Texto em negrito** |
| `*Texto em itálico*` | *Texto em itálico* |
| `- Item da lista` | • Item de lista com marcador |
| `[Nome do Link](URL)` | Link clicável |

---

## 📋 Blocos de Código (Botão de Copiar 1-Clique)

Uma das maiores vantagens do Markdown em plataformas como o GitHub é a criação de **Blocos de Código** usando três crases ```` ``` ````.

Esses blocos exibem uma caixa destacada com um **botão nativo de copiar no canto superior direito**, permitindo que você copie o prompt inteiro com apenas um clique!
