# 🚀 Prompts de Inteligência Artificial para Alta Performance

> **A sua biblioteca open-source de prompts testados e otimizados para Marketing, Vendas, Redes Sociais, Fotografia com IA e Produtividade.**

---

## 📌 Sobre este Repositório

Este repositório foi desenvolvido para ajudar profissionais, criadores de conteúdo, empreendedores e especialistas a utilizarem Inteligência Artificial de forma **estratégica, inteligente e prática**.

Em vez de perder horas tentando adivinhar como pedir algo para a IA, aqui você encontra **prompts prontos para uso ("1-Clique para Copiar")**, desenvolvidos com técnicas avançadas de Engenharia de Prompt (Chain-of-Thought, restrições de saída e parâmetros de estilo visual).

---

## ⚡ Como Usar em 3 Passos Rápidos

1. **Escolha a Categoria**: Navegue pela tabela abaixo e clique no prompt desejado.
2. **Copie o Bloco de Código**: Clique no botão de cópia no canto superior do bloco `[PROMPT PRONTO PARA COPIAR]`.
3. **Cole na sua IA**: Anexe sua imagem ou preencha as variáveis `{ENTRE_CHAVES}` e gere seu resultado no **ChatGPT, Gemini, Claude, Midjourney ou Flux**.
